## What Happens When You Run `shipai full`?

In under 30 seconds, `shipai` executes an end-to-end transformation that would normally take two full engineering days:

### 1. De-AI Forensic Sanitization (Scrubbing the "Agent Slop")
It crawls your entire project and surgically deletes:
- `.cursorrules`, `.cursor/`, `claude.md`, `.windsurf/`, `.clinerules`, and prompt scratchpads.
- AI signature comments (`// Generated by Claude`, `/* v0 by Vercel */`, `# Created with ChatGPT`).
- Lazy disclaimers (`// Note: In production you should replace this mock...`).
- Artificial simulated sleep hacks (`await new Promise(r => setTimeout(r, 1000))`).
- Hardcoded API keys, masking them into safe environment variable templates.

### 2. AST Semantic Rebranding (8-Way Casing)
Using the real **TypeScript Compiler API** (`ts.transform`), it rebrands your symbols, classes, interfaces, JSX tags, route strings, and database schemas:
- `ChatPilot` ➔ `OmniDesk` (PascalCase)
- `chatPilot` ➔ `omniDesk` (camelCase)
- `chat-pilot` ➔ `omni-desk` (kebab-case)
- `chat_pilot` ➔ `omni_desk` (snake_case)
- `CHAT_PILOT` ➔ `OMNI_DESK` (CONSTANT_CASE)
- `Chat Pilot` ➔ `Omni Desk` (Title Case)

It renames Prisma schemas (`schema.prisma`), Drizzle configs, SQL migrations, and even FastAPI metadata in Python backends!

### 3. Mathematical 11-Shade Design System & Vector Assets
Give it one hex color (e.g., `#0ea5e9`):
- Generates an 11-shade mathematical palette (`50` through `950`).
- Injects CSS variables and Tailwind tokens.
- Generates custom vector SVG logos, favicons, Apple touch icons, and high-res OpenGraph social cards (`1200x630`).

### 4. The Self-Healing Universal AI Gateway & Offline Demo Mode
Your client doesn’t have an OpenAI key? Or Claude is hitting rate limits?
The bundled `universalGateway.ts` auto-routes across **OpenAI, Azure, Anthropic Claude, Google Gemini, DeepSeek, Grok, and Local Ollama** via a single environment variable: `AI_PROVIDER=deepseek`.

Best of all: it includes **`OFFLINE_DEMO_MODE=true`**. If keys are missing or offline during an executive presentation, it generates ultra-realistic contextual streaming responses with simulated low-latency typing. **Your client demos will never crash on stage again.**
